# Voucher redemption

A ticket bought with one of an organization's vouchers, in an order that was not cancelled.

## Information kept

- **Voucher code** — the code used
- **Attendee data** — the attendee details the event shares with exhibitors
- **Order** — the order's code
- **Order status** — the order's status
- **Redeemed on** — when the order was placed
